# Bundled terminal fonts

Connex bundles the following open-source terminal fonts. Each font remains under the SIL Open Font License 1.1 included beside its files.

| Font            | Version | Upstream source                                                                                |
| --------------- | ------- | ---------------------------------------------------------------------------------------------- |
| Fira Code       | 6.2     | <https://github.com/tonsky/FiraCode/releases/tag/6.2>                                          |
| JetBrains Mono  | 2.304   | <https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304>                               |
| Cascadia Code   | 2407.24 | <https://github.com/microsoft/cascadia-code/releases/tag/v2407.24>                             |
| Source Code Pro | 2.42.0  | <https://github.com/adobe-fonts/source-code-pro/tree/803b7e23ec97ae58b6232ea76519a76d428ba268> |

SF Mono / Menlo and Consolas are system-font presets only. Their font files are not distributed with Connex. System Monospace uses the platform fallback stack and does not represent a bundled font file.
